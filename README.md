# 优惠券集 · 微信小程序项目说明

> 一个每日自动收集并更新「外卖 / 出行 / 快递」优惠券的微信小程序，让用户一站式领取三大高频生活场景的优惠，并支持 C2C 分享裂变与 CPS 变现。

---

## 一、作品名称

**优惠券集（Coupon Hub）**

- 项目形态：微信小程序（原生 WXML/WXSS/JS 开发）
- 定位：外卖、出行、快递三大高频生活场景的优惠券聚合与每日更新平台

---

## 二、核心功能

### 1. 分类浏览

- 首页顶部横幅 + 分类 Tab（**全部 / 外卖 / 出行 / 快递**），支持横向滚动切换
- 优惠券卡片列表：展示面值、平台、标题、描述、分类标签、进行中/已过期状态，以及「立即领券」引导按钮
- 支持下拉刷新，实时拉取最新券源

### 2. 优惠券详情与领取

- 详情页完整展示：优惠详情、分类、平台、口令、有效期
- **三种智能领取方式**（按券源自动分流）：
    1. 有领券 H5 链接（如美团 CPS 链接）→ 小程序内 **web-view 内嵌打开**领券页，用户不离开小程序
    2. 有对应平台小程序 AppID（饿了么、滴滴、高德、顺丰、京东等）→ **跳转对应小程序**领券
    3. 无上述条件 → **复制口令/链接 + 弹窗引导**去 App 领取
- 领取失败自动降级，保证任何券都能完成「领券」动作，不会卡死

### 3. 分享裂变

- 详情页「分享给好友」按钮 + 右上角菜单转发，自动携带「平台 + 券面值」标题，好友点击直达该券详情
- 支持分享到朋友圈（`onShareTimeline`）
- 首页也支持转发引流

### 4. 每日自动收集更新（核心）

- 每天定时自动执行：**过期券自动下架 + 收集最新优惠券入库**
- 数据源优先走联盟/返利 API，暂无密钥时降级为联网检索各平台公开优惠活动

---

## 三、技术方案与实现思路

### 1. 领券跳转的分流设计（关键技术点）

微信小程序内**无法通过 URL Scheme 直接唤起外部 App**，本项目设计了三级分流：

1. **有 H5 领券链接** → `web-view` 内嵌打开（如美团 CPS 通用红包链接）
2. **有平台小程序 AppID** → `wx.navigateToMiniProgram` 跳转对应小程序（饿了么、滴滴、高德、顺丰、京东等，AppID 经多来源交叉核验）
3. **兜底** → 复制口令/链接 + 弹窗引导去 App

平台 AppID 集中在 `utils/platform.js` 映射表中维护，失效时单点修改即可，页面逻辑零改动。

### 2. 每日自动化（核心机制）

通过定时自动化任务（每天 08:00）驱动 AI Agent 执行：

1. 将 `end_time` 已过期的券标记为 `expired`（下架不删除）
2. 联网/联盟 API 搜集外卖、出行、快递最新优惠券信息
3. 结构化后去重写入 `coupons` 表（`source` 标记来源）
4. 输出本次新增/下架/各类目存量汇报

## 四、作品创新点

1. **「自动收集 + 人工托管」的券源运营模式**：区别于静态优惠券小程序，本项目通过每日定时自动化持续更新券源、自动清理过期券，保证内容始终新鲜有效，用户看到的永远是可用的优惠。
2. **三级智能领券分流**：针对不同券源形态（H5 链接 / 平台小程序 / 纯口令）自动选择最优领取路径，并在失败时自动降级，最大程度缩短「看到券 → 领到券」的路径，兼顾体验与稳定性。
3. **CPS 变现内嵌**：外卖分类接入美团联盟/饿了么联盟的推广链接（带推广位参数），用户在领券下单的同时，运营者可获得佣金，让工具型小程序具备可持续的变现能力。
4. **分享裂变闭环**：详情页一键分享自动携带「平台 + 面值」的诱惑力文案，好友点击直达券详情，形成「领券 → 分享 → 回流」的社交传播闭环。

## 五、Step 模型使用情况

### 1. 每日自动化任务中的模型应用（核心）

每日定时任务由 **AI Agent（大模型）驱动**，模型承担了以下关键工作：

- **联网信息检索与理解**：检索美团、饿了么、滴滴、哈啰、高德、顺丰、菜鸟、京东物流、中通等平台的公开优惠活动信息
- **信息结构化**：从非结构化网页内容中抽取「分类 / 平台 / 标题 / 描述 / 面值 / 口令 / 链接 / 有效期」等结构化字段
- **数据去重与判定**：比对已有券的 `title + platform`，避免重复入库；判断活动时效
- **生成并执行数据操作**：生成 SQL 语句，通过管理通道写入云数据库，完成过期下架与新券入库

### 2. 云服务内置的免密钥 LLM API（能力预留）

- 后端云服务提供了**免密钥的大模型调用能力**（`cloud.llm`），客户端无需自备 API Key
- 当前版本小程序端暂未直接调用；该能力为后续功能预留，例如：
    - 优惠券描述的智能生成与优化
    - 基于用户偏好的个性化券推荐
    - 领券意图的智能识别

### 3. 说明

本项目对模型的运用聚焦于「**自动化内容生产与数据维护**」这一场景 —— 用大模型替代人工完成每日优惠券的搜集、整理与更新，这是作品实现「每日自动更新」核心功能的技术基础，也是区别于传统优惠券小程序的关键所在。
